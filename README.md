# job-portal
Aplikasi Job Portal ini dibangun dengan Next.js dan Tailwind CSS untuk tampilan modern, cepat, serta SEO-friendly berkat dukungan SSR. Data pengguna, lowongan, dan pelamar dikelola dengan Supabase dan Prisma. Platform ini memudahkan orang memposting serta melamar pekerjaan secara online dengan performa optimal.

# Pemakaian
masuk ke directory ```admin-job-portal``` atau ```job-portal```
kemudian jalankan ```npm install```
jalankan server ```npm run dev```
